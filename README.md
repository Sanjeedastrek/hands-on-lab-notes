# Exchange Online Practice Notes

Hands-on notes from practicing **Microsoft Exchange Online** for a Service Desk Analyst role.

The goal was to learn just enough Exchange Online to confidently handle common Tier 1 support tasks — without needing deep admin-level knowledge.

## What This Covers

- Understanding the main Microsoft platforms (Microsoft 365 Admin Center, Exchange Admin Center, Entra, Azure Portal)
- Setting up a practice lab using a Microsoft 365 Business trial
- Creating and managing user accounts
- Working with shared mailboxes and permissions
- Creating and testing distribution lists
- Creating basic mail flow rules
- Using Message Trace to troubleshoot email delivery issues
- Understanding the difference between user mailboxes, shared mailboxes, and distribution lists
- Common day-to-day Service Desk tasks related to Exchange

## Why This Matters

Most Service Desk tickets related to email involve:

- New user onboarding
- Shared mailbox access
- Distribution list membership
- Email delivery problems
- Basic permission changes

These notes focus on the practical skills needed to handle those requests.

## Practice Environment

All practice was done in a free **Microsoft 365 Business trial** tenant.  
This provided a real Exchange Online environment without touching any production system.

## Notes

- Focus was kept on the **GUI** (Microsoft 365 Admin Center + Exchange Admin Center), which is what most Tier 1 analysts use daily.
- Language is kept simple and practical.
- PowerShell was intentionally left out of these notes.

## Skill Summary

- Managed Exchange Online mailboxes, shared mailboxes, and distribution lists
- Assigned mailbox permissions (Full Access / Send As)
- Created and tested mail flow rules
- Used Message Trace for email delivery troubleshooting
- Performed basic user onboarding tasks in Microsoft 365
